# Gemini Extended Suite (Manifest V3)

> **対象ブラウザ**: Chromium系（Google Chrome & Microsoft Edge）  
> **対象プラットフォーム**: Gemini Web Interface (`gemini.google.com`)  
> **バージョン**: 1.2.0

---

## 1. 概要
Gemini Web UIに対応した、オールインワン作業支援ブラウザ拡張機能です。  
クリエイティブワーク、長編創作、リサーチを快適に行うためのスリムなモデル切替バー、フォルダ整理、高精度Markdownエクスポート、公式使用量モニター、目次ジャンプ機能を提供します。

---

## 2. 機能一覧

| 機能 | モジュール | 説明 |
| :--- | :--- | :--- |
| **モデル＆思考モード選択バー** | `model_switcher.js` | 入力欄直上にスリム＆邪魔にならないミニマル設計で配置。`3.5 Flash-Lite`, `3.8 Flash`, `3.1 Pro` のワンクリック切替 ＋ `🧠 思考モード` の独立ON/OFFトグル。 |
| **フォルダ管理（クイック移動）** | `sidebar_folders.js` | サイドバー上部に「＋ 新規フォルダ」。スレッド横の「📁」ボタンからワンクリックでフォルダへ振り分け。 |
| **Markdown全文エクスポート** | `exporter_md.js` | 画面右上バーに「📥 MD保存」ボタン。YAMLフロントマター、思考プロセス（Thinking）含有/除外切り替え、コード言語・表の完全抽出。 |
| **公式使用量・クォータ常時表示** | `usage_monitor.js` | 画面右上バーに公式の使用量（例: `1% 使用中`、`16:18リセット`）を表示。公式画面からの自動スクレイピング・同期対応。 |
| **Chat Enhancer** | `chat_enhancer.js` | 📑目次・ミニマップ（高速点滅防止＆スムーズジャンプ）、⤢全幅ワイド表示（85%〜100%）、🔢入力文字数・行数カウンター、🔔生成完了デスクトップ通知。 |
| **ポップアップ管理画面** | `popup/popup.html` | 各機能のON/OFFトグル、フォルダおよび設定データのJSONバックアップ・リストア。 |

---

## 3. インストール・再読み込み手順（開発者モード）

1. **Google Chrome または Microsoft Edge** を開きます。
2. アドレスバーに以下を入力:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. 画面の **「デベロッパー モード（開発者モード）」** をオンにします。
4. **「パッケージ化されていない拡張機能を読み込む」**（Edgeでは「展開して読み込み」）から本フォルダを選択します。
5. 既に読み込み済みの場合は、**「更新（リロードアイコン ↻）」** をクリックします。
6. `https://gemini.google.com` にアクセス（またはF5で再読み込み）すると、最新の機能が反映されます。
